Welcome to the Django ReCaptcha CSP Demo

ℹ️ About this demo: This site demonstrates the django-recaptcha-csp package, which provides Content Security Policy (CSP) nonce support for django-recaptcha widgets.

🎯 What is django-recaptcha-csp?

This package solves the problem of using Google reCAPTCHA with strict Content Security Policies. It provides CSP-aware widget classes that automatically inject nonces into inline scripts, allowing reCAPTCHA to work without violating your CSP rules.

✨ Key Features

  • Automatic nonce injection - No manual passing required!
  • Middleware-based - Works seamlessly with django-csp or custom CSP middleware
  • Multiple widget types - Checkbox and Invisible reCAPTCHA v2
  • Drop-in replacement - Minimal changes to existing code

📚 How It Works

  1. Middleware generates a nonce for each request
  2. Nonce is stored in thread-safe context storage
  3. Widgets automatically retrieve the nonce
  4. Templates render with proper CSP nonce attributes

⚙️ Quick Setup

# settings.py
INSTALLED_APPS = [
    ...
    'captcha',  # django-recaptcha
    'recaptcha_csp',  # This package
]

MIDDLEWARE = [
    ...
    'csp.middleware.CSPMiddleware',  # Your CSP middleware
    'recaptcha_csp.middleware.CSPNonceMiddleware',  # Add after CSP
]

# forms.py
from captcha.fields import ReCaptchaField
from recaptcha_csp.widgets import CSPReCaptchaV2Checkbox

class MyForm(forms.Form):
    captcha = ReCaptchaField(widget=CSPReCaptchaV2Checkbox)

# views.py - No changes needed!
form = MyForm()  # That's it!
