How django-recaptcha-csp Works

  1. Middleware generates nonce
    SimpleCSPMiddleware creates a unique nonce for each request
  2. Nonce stored in context
    CSPNonceMiddleware stores it in thread-safe context storage
  3. Widgets retrieve nonce
    CSPReCaptchaV2Checkbox/Invisible automatically get the nonce
  4. Templates render with nonce
    Inline scripts include nonce="{{ csp_nonce }}" attribute

CSP Header Example

This demo uses a simple CSP header like this:

Content-Security-Policy: 
    script-src 'self' 'nonce-{{ csp_nonce }}' 
        https://www.google.com/recaptcha/ 
        https://www.gstatic.com/recaptcha/;
    frame-src https://www.google.com/recaptcha/ 
        https://www.gstatic.com/recaptcha/;
    style-src 'self' 'unsafe-inline';
    default-src 'self';

Production Setup

For production, use a proper CSP library like django-csp:

# Install
pip install django-csp

# settings.py
MIDDLEWARE = [
    ...
    'csp.middleware.CSPMiddleware',  # django-csp
    'recaptcha_csp.middleware.CSPNonceMiddleware',  # Our middleware
]

# CSP Settings
CSP_DEFAULT_SRC = ("'self'",)
CSP_SCRIPT_SRC = (
    "'self'",
    "https://www.google.com/recaptcha/",
    "https://www.gstatic.com/recaptcha/",
)
CSP_FRAME_SRC = (
    "https://www.google.com/recaptcha/",
    "https://www.gstatic.com/recaptcha/",
)
CSP_INCLUDE_NONCE_IN = ['script-src']
